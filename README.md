# Quebra Mundos
Um jogo muito legal que meu amigo pediu para eu criar.

## Sobre
Jogo jeito em *.ps1* com imagens e coisas salvas em um arquivo *.json*, feitos para não ocupar nada de espaço em teu pc, ótimo quando estiver entediado.

## Requerimentos
- Um pc qualquer com **Windows**
- **Windows** *PowerShell*
- Processador *amd64*
- Você
